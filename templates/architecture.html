System design

Architecture and Responsibilities

SportStats combines Flask routes, statistical services, event-graph analytics, and a YOLO/OpenCV video pipeline behind one web interface.

Authors Daniel Emeka-Ilozor Assylkhan Balmukhanov
Browser UI
Flask app factory
Analytics services
Data, model assets, and generated outputs
Web layer

sportstats.web

Server-rendered pages, form validation, video uploads, JSON API responses, runtime folders, and error handling.

Forecasting

prediction.py

Poisson score draws with Elo, attack, and defense inputs for match probabilities and likely scorelines.

Shot model

xg_calculator.py

Distance, goal angle, and body-part inputs converted into expected-goal probability.

Ratings

elo_engine.py

International results are converted into Elo ratings used by the ratings page and World Cup model.

Tournament model

wc_predictor.py

2026 groups, Elo-driven match xG, qualification rules, fixed knockout path, and bronze/final projections.

Event graph

passing_network.py

Pass-event JSON validation, average player positions, weighted links, central player, density, and progression metrics.

Computer vision

sportstats.vision

YOLO tracking, team assignment, ball interpolation, possession, camera correction, perspective transform, speed, and distance.

Model assets

model_assets.py

Checks local `models/best.pt`, downloads the public release asset when configured, and keeps generated video outputs under `static/outputs`.

Implemented

  • Match predictor with Elo/team-strength inputs
  • xG calculator with shot-map visualization
  • International Elo ratings table
  • 2026 World Cup projection with group and knockout stages
  • Passing-network editor with JSON validation and live event/player counts
  • YOLO football video analysis with trained-model download support
  • Docker setup, CI checks, unit tests, and project documentation

Not implemented

  • Automated pass extraction from video into the passing-network page
